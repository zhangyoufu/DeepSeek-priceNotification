# DeepSeek Price Notification

Somehow, DeepSeek does not provide any public document, showing their API platform announcement history.

This repo tries to [track every change](https://github.com/zhangyoufu/DeepSeek-priceNotification/commits/master/output.txt) of their announcements (known as `priceNotification` per their frontend code).

This repo alse serves an [Atom feed](https://zhangyoufu.github.io/DeepSeek-priceNotification/atom.xml) in case you need.
